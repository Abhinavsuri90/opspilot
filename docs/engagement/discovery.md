# Discovery template

## Current workflow
Describe where documents enter, who handles them, and each handoff through completion.

## Stakeholders
List decision makers, operators, reviewers, system owners, and their responsibilities.

## Pain points
Record observed delays, rework, errors, and exceptions with sources for each claim.

## Volumes and document types
Record measured daily and peak volumes, file formats, page counts, and variation.

## Systems involved
List source and destination systems, integration options, ownership, and access constraints.

## Constraints and open questions
Capture security, residency, retention, policy, timing, and unresolved questions.
